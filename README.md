# sfu-cv-kaggle-comp

Стенд-соревнование по компьютерному зрению для аудитории, далёкой от программирования.
Спутник доклада «Анализ изображений: методы и промышленные применения».

Участник открывает ноутбук в браузере, запускает его и проходит лестницу задач —
детекция, сегментация, трекинг, глубина, — получая на каждой ступени картинку,
разбор ошибок и позицию в лидерборде.

## Состояние

**Ресерч.** Реализации пока нет.

## Локальное окружение

```bash
py -3.10 -m venv .venv
.venv/Scripts/python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
.venv/Scripts/python.exe -m pip install -r requirements.txt
```

Отдельная строка для torch не случайна: обычный PyPI на Windows отдаёт сборку без CUDA.

| Папка | Что | Размер |
