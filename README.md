# sfu-cv-kaggle-comp

Стенд-соревнование по компьютерному зрению для аудитории, далёкой от программирования.
Спутник доклада «Анализ изображений: методы и промышленные применения».

Участник открывает ноутбук в браузере, запускает его и проходит лестницу задач —
детекция, сегментация, трекинг, глубина, — получая на каждой ступени картинку,
разбор ошибок и позицию в лидерборде.

## Состояние

**Ресерч.** Реализации пока нет.

## Ноутбук занятия

[notebooks/1_chto-vidit-mashina.ipynb](notebooks/1_chto-vidit-mashina.ipynb) — одиннадцать
разделов: обзор с пяти камер, поиск объектов по текстовому запросу, сопровождение
роликом, ручная разметка сцены, лазерный дальномер, глубина по одному снимку,
пути объектов на плоскости.

Собирается из [tools/build_notebook.py](tools/build_notebook.py): тексты правятся там,
ноутбук пересобирается целиком.

## Локальное окружение

```bash
py -3.10 -m venv .venv
.venv/Scripts/python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
.venv/Scripts/python.exe -m pip install -r requirements.txt
```

Отдельная строка для torch не случайна: обычный PyPI на Windows отдаёт сборку без CUDA.

## Веса

Лежат в `models/`, в git не уходят (см. `.gitignore`).

| Папка | Что | Размер |
