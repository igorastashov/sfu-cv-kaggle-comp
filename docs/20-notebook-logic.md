# Стенд «Что видит машина». Логика работы

Документ описывает устройство практического занятия: какие данные используются, какие модели, что происходит в каждом разделе и что делает участник.

## Кто работает со стендом

Научные и прикладные специалисты вне компьютерного зрения. Опыта программирования не предполагается. Участник запускает готовые ячейки и меняет значения в одной из них.

Занятие рассчитано на 90 минут.

## Замысел

Обычное практическое занятие по анализу изображений строится вокруг обучения модели. Такой путь для неподготовленной аудитории закрыт: обучение занимает часы, а результат зависит от разметки, которой у слушателя нет.

Стенд устроен иначе. Все модели взяты готовыми, обучение не проводится. Участник задаёт вопрос словами и настраивает границы принятия решения. Одна итерация занимает от десяти до двадцати пяти секунд, поэтому за занятие человек делает десятки попыток.

Из этого следует главный приём. Основной настройкой становится не число, а формулировка запроса. Замена одного слова меняет результат сильнее, чем любая другая доступная ручка. Проверено на данных: запрос про легковую машину дал 4 объекта, запрос про транспортное средство — 7 при эталоне 11.

## Данные

Двадцать секунд съёмки с движущегося автомобиля, город, дневное освещение. Открытый набор, разработанный для исследований в области автономного вождения.

| Свойство | Значение |
| --- | --- |
| Кадров | 199, съёмка 10 раз в секунду |
| Камер | 5, круговой обзор |
| Размер кадра | 1920 × 1280 |
| Размеченных рамок | 17 404 |
| Номеров объектов | 353 |
| Классы разметки | транспорт, пешеходы, велосипедисты |
| Разметка по точкам изображения | 99 кадров на 5 камер, 29 классов |
| Дальномер | лазерный, круговой, 19 828 измерений на кадр |
| Объём | 601 МБ |

Разметка выполнена людьми и служит эталоном. Участник ничего не размечает. Все показатели считаются сравнением с этим эталоном автоматически.

Существенная особенность набора: разметка по точкам изображения положена не для всех записей. Из 202 проверочных записей полноценную разметку имеют 20. Запись для стенда отобрана по этому признаку.

## Модели

Ни одна модель не обучалась под эту задачу.

| Задача | Что делает модель | Обучение под задачу |
| --- | --- | --- |
| Обнаружение и выделение объектов | принимает текстовый запрос, возвращает контур каждого объекта и его номер | нет |
| Сохранение номера во времени | помнит объекты по кадрам, номер не сбивается | нет |
| Расстояние по одному снимку | возвращает относительную глубину, приводится к метрам по дальномеру | нет |
| Сравнение изображений | сжимает участок в набор чисел, похожие участки дают близкие наборы | нет |
| Поиск объектов геометрией | обучаемых частей не содержит вовсе | не применимо |

Первая модель закрывает три задачи сразу. Один проход по записи даёт прямоугольник вокруг объекта, его контур и номер, сохраняемый между кадрами. Это существенно для занятия: участник меняет одно слово и одновременно видит, как меняются рамки, контуры и подсчёт.

## Что участник меняет

Изменяемых значений четыре. Все они собраны в одном разделе, остальные разделы выполняются без правки.

| Настройка | Действие |
| --- | --- |
| Запрос | слово или фраза, которую ищет модель |
| Граница уверенности | ниже неё объект отбрасывается |
| Минимальная длина следа | объект, замеченный в меньшем числе кадров, не засчитывается |
| Цель сравнения | с каким классом эталона сверяется результат |

## Показатель для таблицы результатов

Сравнивается число объектов, прошедших через кадр за отрезок, с числом объектов в эталоне. Показатель выбран не абстрактный. Он читается без подготовки: система насчитала 47 объектов, в действительности их 51.

Показатель зависит от всей последовательности шагов сразу. Слишком низкая граница уверенности добавляет ложные срабатывания. Слишком высокая теряет настоящие объекты. Потеря объекта между кадрами приводит к тому, что он заводится заново и считается дважды.

## Оговорки

Их следует проговорить вслух, иначе занятие превращается в рекламу.

Ни одна формулировка запроса не дотягивает до эталона в 11 объектов. Недосчёт остаётся и настройкой не лечится. Это показывает границу применимости готовой модели: подбор слов не всесилен.

Разметка по точкам изображения в этом наборе получена автоматической процедурой, а не человеком. Сравнение идёт с машинным эталоном.

Показатель поиска похожего на этом отрезке достигает предельного значения. Причина не в качестве поиска, а в составе выборки: соседние кадры одного объекта почти одинаковы, и задача оказывается слишком лёгкой. Это самостоятельный вывод, полезный для слушателя. Показатель может расти без улучшения решения.

Положение объекта на плоскости восстанавливается по углу обзора камеры и расстоянию до контура. Это приближение. Для точного положения нужны данные о повороте камеры, в стенде они не используются.

Вычисления требуют ускорителя. На обычном процессоре обработка кадра занимает десятки секунд, и темп занятия теряется.

## Соответствие лестнице задач

Стенд повторяет порядок изложения доклада, поэтому практика ложится на теорию без переходов.

| Раздел стенда | Раздел доклада |
| --- | --- |
| Обнаружение по запросу | обнаружение объектов, базовые модели |
| Контуры и площади | сегментация |
| Устойчивые номера | сопровождение объектов |
| Кривая границы принятия решения | поиск отклонений от нормы |
| Расстояние и вид сверху | трёхмерные и объёмные данные |
| Решение без обучения | классическое компьютерное зрение |
| Сравнение изображений | векторные представления и поиск похожего |
| Ручная разметка сцены | введение, стоимость подготовки данных |

Главный вывод доклада стенд подтверждает от обратного. Участник не размечает ничего, и результат упирается в предел, который настройкой не преодолевается. Узкое место находится в разметке, а не в модели.
